# AGENTS.md

## Project Context

This is a user-owned React/Vite static website. Keep changes focused, preserve existing project conventions, and start with `README.md` for setup and deployment instructions.

## Working Notes

- Run locally with `npm install` and `npm run dev`.
- The site has no server-side backend. Visitor submissions are stored in that browser's `localStorage`, not shared with other visitors.
- Do not add secrets to frontend code or `VITE_` environment variables.
- Run the relevant checks from `package.json` before finishing code changes.
